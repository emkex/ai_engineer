**AI-монтаж — 3 инструмента**

**Remotion** — React → видео. Логика покадровая ("на 30-м кадре элемент тут"). Хорош для автоматизации однотипных видео по шаблону. Минусы: нестабильный результат, баги, все видео одинаковые, мелкие правки — проще руками.

**HyperFrames** — HTML/CSS/GSAP → видео. Таймлайн вместо кадров, меньше багов, из коробки красивее (HDR, blur, кинетический текст). Лучше для motion-графики. Дизайн через design.md файл.

**Adobe After Effects MCP** — агент пишет JSX-скрипты → импортирует в AE → собирается монтаж. Ближе к продакшену чем первые два. Нужно знать базу AE для ручных правок. Автор делал каждую сцену за 2 промпта: черновик → правки.

**Вывод автора:** AE MCP > HyperFrames > Remotion. Remotion только если нужна массовая автоматизация по шаблону.

**Связь с твоим стеком:** всё это MCP-серверы — подключаются к агенту как инструменты. Та же механика что filesystem или Brave Search, просто инструмент = After Effects.

# Wolfram — заметки

## Что это

Computational knowledge engine. Не поисковик (не возвращает ссылки), не энциклопедия (не только хранит). Три компонента:
1. **Wolfram Language** — символьный язык: числа, формулы, данные, графика — всё как символьные выражения, над которыми делается математика.
2. **Курируемая база знаний (Computable Data)** — выверенные вручную данные (страны, химэлементы, финансы, константы). Не веб-краулинг.
3. **Вычислительный движок (Wolfram Engine)** — вычисляет ответ алгоритмами, а не достаёт готовый.

Девиз: computed results not hallucinations; computation not retrieval; curated data not web crawls.

## Два типа ответов и доверие к ним

- **Вычисленные** (интеграл, уравнение, статистика): доверие = детерминированная математика. Алгоритмы доказаны, воспроизводимы (один запрос → один ответ всегда), проверены десятилетиями в Mathematica. Можно проверить вручную на простом случае.
- **Фактические** (ВВП, свойства веществ): доверие = ручная курация источников. Wolfram показывает источник. Критичные цифры всё равно сверять с первоисточником.

Формального публичного аудита всей базы нет; доверие на репутации (35+ лет, академ-стандарт) + воспроизводимости. Но на порядок надёжнее LLM, который выдумывает и число, и источник.

## Wolfram Engine — зачем отдельно

Движок без интерфейса = голое вычислительное ядро. Mathematica = Engine + notebook для человека. Engine нужен когда вычисления нужны программе/агенту, не человеку за экраном. Local MCP запускает Engine у тебя. Hosted MCP использует Engine на серверах Wolfram — ставить ничего не надо.

## Крупные данные

Можно тянуть исторические ряды: `FinancialData["CL", {1975,1,1}]` (нефть). Приходят как вычислимый объект — сразу графики, статистика, корреляции. Макро-ряды (нефть, газ, валюты) — отлично. Нишевое (РЗМ) — проверять покрытие.

## API — от простого к мощному

- **Short Answers API** — одна строка. Быстрая проверка числа.
- **Simple API** — картинка результата.
- **LLM API** — текст под скармливание в модель. Для агентов на естественном языке.
- **Full Results API** — полная структура (pods), disambiguation, drilldown. Серьёзные интеграции.
- **Agent One / CAG APIs** — комбинированная система LLM+Wolfram.

Бесплатный тир API: **2000 запросов/мес, некоммерческий**. AppID на developer.wolframalpha.com.

## MCP (рекомендуемый путь для агента)

Официальный, лучше самописного. Два варианта:

**Hosted (MCP Cloud Service)** — ничего не ставишь. URL `https://services.wolfram.com/api/mcp` + Bearer-ключ с `account.wolfram.com/developer-tools/api-keys`. ← ВЫБОР ДЛЯ МЕНЯ.

**Local (AgentTools paclet)** — требует Wolfram Engine/Mathematica/Wolfram|One на машине. Для кастомных инструментов, приватности. `PacletInstall["Wolfram/AgentTools"]`.

### Три инструмента MCP

- `WolframLanguageEvaluator` — выполняет код Wolfram Language. **Дефолт для всех вычислений.**
- `WolframAlpha` — запросы на естественном языке. Для фактов без кода.
- `WolframContext` — семантический поиск по документации. Найти нужную функцию/синтаксис перед вычислением.

### Правило маршрутизации

По умолчанию `WolframLanguageEvaluator`. `WolframAlpha` только для прямых фактов без кода. `WolframContext` когда нужен синтаксис. НЕ использовать для мнений, креатива, лингвистики, где хватает приблизительного рассуждения.

### Если нет результата

Переформулировать проще/буквальнее → разбить на подзапросы → проверить синтаксис через WolframContext → для субъективных не повторять.

## Подписки — что и нужно ли

- **Wolfram Alpha Pro** ($5 студ / $9.99 обычн / мес): для РУЧНОЙ работы на сайте — пошаговые решения, загрузка файлов, без рекламы. НЕ включает API. Для агента не нужна. Полезна точечно для репетиторства (пошаговые решения, Problem Generator).
- **API** — отдельный биллинг, бесплатный тир 2000/мес.
- **MCP Cloud Service** — отдельный ключ.
- **Mathematica / Wolfram|One** — лицензии на софт, только для local MCP и глубокой символьной работы.

Вердикт: платить пока НЕ нужно. Claude Pro + бесплатный Wolfram API/MCP = рабочий сетап.

## Где Wolfram силён / где нет (для моих доменов)

СИЛЁН: математика (оптимизация портфеля, квадратичное программирование), статистика (распределения, тесты, регрессия), химия (свойства, стехиометрия, реакции), физика, единицы, графики, репетиторство (пошаговые решения).

Wolfram = вычислительный коцпроцессор и проверочная машина. Не советник по стратегии/выбору метода.

## Альтернативные источники проверенных данных (собрать как MCP/tools агента)

- **SymPy** — бесплатная Python символьная математика. Ближайший бесплатный аналог вычислительной части Wolfram. Дать агенту как tool.
- **FRED API** — экономические данные ФРС, бесплатно. ← под экономику.
- **World Bank API** — макроэкономика стран, бесплатно.
- **yfinance / Yahoo Finance** — рынки.
- **Wikidata** — структурированные факты, бесплатный API.
- **Semantic Scholar API / arXiv API** — поиск научных статей и методологий, бесплатно. ← для "какой метод выбрать, на что обратить внимание".
- **PubChem** — база химсоединений, бесплатный API. ← под химию.
- **RDKit** — химинформатика (Python).

Стратегия: не один Wolfram, а набор детерминированных проверочных источников под каждый домен поверх вероятностного LLM. Wolfram считает/проверяет математику; Semantic Scholar/arXiv ищут метод; FRED даёт эконом-данные; PubChem — химию.

## Принцип использования

LLM вероятностный (галлюцинирует число и источник). Эти инструменты детерминированные/курируемые. Использовать как ВТОРОЙ ЗАБОР: посчитал важное в Python → перепроверь критичный кусок через Wolfram. Инструмент усиливает того, кто знает что считать — не заменяет понимание.
